# `crt-lottes-fast` provenance

This shader is copied from `libretro/slang-shaders` commit
`4812a82f6c9a11cc8b5a7447040a98c9fc80c00e`:

`crt/shaders/crt-lottes-fast.slang`

The source declares the Unlicense/public-domain dedication retained in the
shader and repeated in `crt_lottes_fast_unlicense.txt`. Its SHA-256 is
`576eddc662ac4f77909c0c14dbd5a16ac4164e50c67527fff634316f4441c482`.

The VAeg-owned preset is intentionally separate from the upstream file. The
audited closure contains no include, image, LUT, or generated-header
dependency. No other file from `slang-shaders` is bundled.
