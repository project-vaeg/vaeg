## Root cause and correction

The G65 `FF /7` population completed normally but failed on final
architectural state. The complete 5,000-row reconstruction proves the
observable contract:

- normal termination;
- `IP` advances by the represented instruction length;
- `FLAGS` are preserved;
- `SP` is decremented by two;
- the selected `r/m16` value is written to the stack at the decremented `SP`;
- for `r/m = SP`, the written value is the decremented `SP`;
- memory source operands are read but not overwritten.

The active dispatch table incorrectly routed `FF /7` to a POP-like helper.
M65a replaces that table entry with an `FF /7`-owned push helper. The helper
uses existing `r/m16` push behavior for normal register and memory forms and
handles the `SP` alias so only M65a-owned `FF /7` changes. The existing
`FF /6` helper remains unchanged for M65d ownership.
